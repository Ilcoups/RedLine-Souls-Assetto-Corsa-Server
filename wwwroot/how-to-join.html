📚 Complete Setup Guide

Step 1: Install Assetto Corsa

If you don't already own Assetto Corsa, purchase it on Steam. The base game is all you need - DLC is optional and not required for RedLine Souls.

  • Platform: PC only (Windows)
  • Price: Usually $19.99 (often on sale for $4-7)
  • Storage: ~15GB required

Step 2: Download Content Manager

Content Manager (CM) is the essential modding tool for Assetto Corsa. It makes installing mods, managing cars, and joining servers incredibly easy.

  1. Go to assettocorsa.club/content-manager.html
  2. Download the "Content Manager" version (free)
  3. Extract the .zip file to a folder (e.g., C:\Games\Content Manager)
  4. Run Content Manager.exe
  5. Follow the setup wizard to detect your AC installation

Optional: Consider upgrading to Content Manager Full (paid) for extra features, but the free version works perfectly for RedLine Souls.

Step 3: Join RedLine Souls Server

There are two ways to join:

Option A: Quick Join Link (Easiest)

  1. Click the "Join Server" button on our homepage
  2. Your browser will prompt to open Content Manager
  3. Click "Allow" to let CM handle the connection
  4. CM will open directly to the server

Option B: Manual Server Browser

  1. Open Content Manager
  2. Click the "Online" tab
  3. Click "Server Browser" or press the search icon
  4. Search for "RedLine Souls" or enter IP: 188.245.183.146:8081
  5. Click the server to view details
  6. Click "Join" button

Step 4: Download Required Mods (Automatic)

When you first join RedLine Souls, Content Manager will automatically download all required content:

  • Shutoko Revival Project (SRP) - The Tokyo highway map (~2GB)
  • Car Packs - Euro supercars and performance vehicles (~500MB-1GB)
  • Server Config - Traffic settings, teleport points, etc.

First join: Expect 5-10 minutes of downloading depending on your internet speed.

Subsequent joins: Instant! Mods are cached locally.

💡 Tip: Don't close Content Manager while mods are downloading. You'll see a progress bar at the bottom.

Step 5: Start Racing!

Once the mods are downloaded and you're connected:

  1. Select a car from the available list (any car works!)
  2. Click "Drive" to spawn on the Shutoko highway
  3. Explore! You'll spawn at a random location with AI traffic

Essential Commands (Type in Chat)

  • /help - Show all available commands
  • /tp [number] - Teleport to location (1-217)
  • /pit - Return to pits
  • /topspeed - View top speed leaderboard

Popular Teleport Locations

  • TP 1: Wangan (Bayshore Route - perfect for top speed runs)
  • TP 50: C1 Inner Loop (technical corners)
  • TP 100: Shuto Highway Junction
  • TP 150: Rainbow Bridge

🔧 Troubleshooting

❌ "Could not connect to server"

Solution:

  • Check your firewall - allow Assetto Corsa and Content Manager
  • Verify server is online on our homepage status widget
  • Try restarting Content Manager
  • Disable VPN if using one

❌ "Missing car/track" error

Solution:

  • Make sure you're using Content Manager (not vanilla AC launcher)
  • Check "Download missing content" is enabled in CM settings
  • Manually search for the missing mod on RaceDepartment or AssettoLand

❌ Game crashes on join

Solution:

  • Update your graphics drivers
  • Lower graphics settings in AC options
  • Verify AC game files in Steam (right-click AC → Properties → Local Files → Verify)
  • Disable Custom Shaders Patch (CSP) temporarily to test

❌ "Checksum mismatch" error

Solution:

  • This means your mod version differs from the server's
  • Let Content Manager re-download the mod automatically
  • Delete local cache: CM Settings → Content Manager → Clear cache
