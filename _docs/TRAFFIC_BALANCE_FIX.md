# Traffic Speed & Bouncing Fix

## Проблемы / Problems

1. **AI машины трясутся/прыгают** (как на пружинах) - подвеска ненатурально подскакивает
   - AI cars bouncing/shaking unnaturally (like on springs) - suspension jumps

2. **Скорости не сбалансированы:**
   - 2-полосные дороги (C1) - слишком быстро для города
   - 3-полосные шоссе (Wangan) - слишком медленно для скоростной трассы
   
   - 2-lane roads (C1) - too fast for city driving
   - 3-lane highways (Wangan) - too slow for expressway

---

## Решение / Solution

### 1. Исправлено подпрыгивание / Fixed Bouncing

**Проблема:** AI машины слишком близко к дороге + неправильный диаметр колес = тряска

**Fixes:**
- ✅ **SplineHeightOffsetMeters: 0 → 0.15** (поднял AI над дорогой на 15см)
- ✅ **TyreDiameterMeters: 0.65 → 0.75** (увеличил диаметр колес на 15%)
- ✅ **DefaultDeceleration: 6 → 5** (мягче торможение)
- ✅ **DefaultAcceleration: 3.5 → 3.0** (мягче разгон)
- ✅ **SmoothCamber: true** (уже было включено - сглаживание неровностей)

**Результат:** AI машины едут плавно, без прыжков!

---

### 2. Пересбалансированы скорости / Rebalanced Speeds

#### 🏔️ Одна полоса (Touge, горы)
- **Скорость:** 95-125 км/ч (было 100-140)
- **Характер:** Быстро, легкий трафик

#### 🏙️ Две полосы (C1, город) - ЗАМЕДЛЕНО!
- **Скорость:** 60-110 км/ч (было 60-150!)
- **Правая полоса:** ~60-75 км/ч
- **Левая полоса:** ~85-110 км/ч
- **Характер:** Умеренная скорость для города

#### 🛣️ Три полосы (Wangan, шоссе) - УСКОРЕНО!
- **Скорость:** 90-170 км/ч (было 60-160)
- **Правая полоса:** ~90-100 км/ч (грузовики)
- **Средняя полоса:** ~110-130 км/ч
- **Левая полоса:** ~150-170 км/ч (быстрые машины!)
- **Характер:** Быстрое шоссе, большая разница в скоростях

## Как это работает / How It Works

### Base Speed Settings:
- MaxSpeedKph (база): **110 км/ч**
- RightLaneOffsetKph: **40 км/ч** (левая полоса быстрее)
- MaxSpeedVariationPercent: **15%** (±15% случайная вариация)

### Lane Overrides:

**1-Lane (Touge):**
```yaml
MaxSpeedKph: 110
RightLaneOffsetKph: 15
→ Скорость: 95-125 км/ч
```

**2-Lane (C1 City):**
```yaml
MaxSpeedKph: 85 (REDUCED!)
RightLaneOffsetKph: 25
→ Right: 60-75 km/h
→ Left: 85-110 km/h
```

**3-Lane (Wangan Highway):**
```yaml
MaxSpeedKph: 130 (INCREASED!)
RightLaneOffsetKph: 40
→ Right: 90-100 km/h (slow lane)
→ Middle: 110-130 km/h (passing)
→ Left: 150-170 km/h (FAST LANE!)
```

## 2025-11-22 Update – SRP 0.9.3 Mesh Adjustments

- 🔄 **SplineHeightOffsetMeters: 0.15 → 0.02** — SRP 0.9.3 подправил высоту дорожного меша, поэтому прежние +15 см теперь делают машины «парящими» на ~20 см. Новое значение оставляет небольшой запас (2 см), чтобы избежать старой проблемы с подпрыгиванием, но визуально прижимает трафик к асфальту.  
- ⚠️ **Следить:** если вернётся вибрация/пробуксовка, протестируйте 0.03–0.05. Если машины всё ещё в воздухе, попробуйте 0.0 или -0.02.  
- 🔁 Не забудьте после правок перезапустить сервер: `./stop_server.sh && ./start_server.sh`
